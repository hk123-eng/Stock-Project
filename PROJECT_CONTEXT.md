# PROJECT CONTEXT — Cloud-Based Stock Price Monitoring and Prediction System

_Last updated: 2026-10-06. Phases 1–7 implemented and tested; Phase 8 item 1 (prediction scoring + model health) deployed 2026-10-06. Sections 3–6 reflect live AWS state verified on 2026-10-05. Phase 0 audit findings (2026-10-04) are kept in §5._

## 1. Objective
Build a low-cost, fully cloud-based stock monitoring and prediction system for a college Cloud Computing + ML project: collect real stock data, store it, calculate signals, run an LSTM prediction, persist predictions, generate alerts, and expose results through an authenticated dashboard.

**Status (2026-10-05):** the live pipeline works end to end on real data. Three things are outstanding:
- **CloudFront:** blocked until AWS Support verifies the account.
- **Signed-in test:** waiting for the user to create their Cognito login.
- **Step Functions logging:** needs an extra permission.

The LSTM has been evaluated honestly and does **not** beat a naive baseline (§7).

### Data model
- **`stock-prices`** (`symbol` / `timestamp`):
  - **Real rows:** `timestamp` is the US close time in UTC (`YYYY-MM-DDT20:00:00Z` during US daylight time, `T21:00:00Z` otherwise). Attributes: `trade_date`, `open`, `high`, `low`, `close`, `volume` (all Numbers), `source=alphavantage`, `data_type=real`, `adjusted=false`, `ingested_at`, `raw_s3_key`. As of 2026-10-05 there are 100 rows, 2026-05-12 → 2026-10-02.
  - **114 legacy synthetic rows:** unchanged (verified byte-identical to the audit snapshot). They have no `source` attribute, and every reader ignores untagged rows.
- **`stock-predictions`** (`symbol` / `as_of_date`): `predicted_close`, `last_close`, `predicted_change_pct`, `target=next_trading_day_close`, `target_date_estimate`, window dates, `inputs_outside_scaler_range`, `scaler_range`, `model_version`, `execution_id`, `created_at`.
  - Added by `stock-evaluate` once the next real trading day exists (written once, conditional on `attribute_not_exists(scored_at)`): `actual_date`, `actual_close`, `error` (predicted − actual), `abs_pct_error`, `naive_error` (last_close − actual), `naive_abs_pct_error`, `scored_at`.
- **`stock-signals`** (`symbol` / `trade_date`): `close`, `prev_close`, `change_pct`, `sma_20`, `sma_50`, `rsi_14`, `volatility_20d_pct`, the prediction, `alerts[]`, `alert_sent_at` and `alert_execution` (used to block duplicate alerts).
  - The 2026-10-02 item holds a **test** alert raised with a temporary `PRED_MOVE_PCT=0.1`; it is visible as `alert_execution …:test-signals-alert-2`. The production threshold is 2%.

## 8. Market-data decision (Alpha Vantage)
**Decided 2026-10-04 and implemented 2026-10-05: Alpha Vantage, free API key, `TIME_SERIES_DAILY`, `outputsize=compact`.**

**Free-tier limits:**
- 25 requests per day.
- Each pipeline run uses 1. Testing on 2026-10-05 used about 8.

**Caveats (each is handled in the code or docs):**
1. **Unadjusted prices.** `TIME_SERIES_DAILY_ADJUSTED` is premium-only. Rows carry `adjusted=false`, and a split would show up as a false price jump.
2. **100-data-point limit.** `compact` returns only the latest 100 trading days; `full` is premium-only. That is enough for the 60-row window, but it limits backtesting to 40 points.
3. **The API key travels in the URL** (`apikey=` query parameter). The key lives in SSM SecureString and is fetched at runtime. URLs are never logged, and errors are re-raised without them. Logs and archives were searched to confirm the key isn't there.
4. **Group-project terms question.** The licence covers "personal, non-commercial use"; use "on behalf of a … partnership … or any other association" counts as commercial. **If this is a team project, email support@alphavantage.co** to confirm the use is allowed and request educational verification (which also lifts the request limits).

**Alternatives rejected:**
- Twelve Data free plan: "internal non-display" use only.
- Tiingo free plan: forbids persistent storage.

## 9. Cost
- **Expected:** $0.00/month within free tiers (approved by the user 2026-10-05). Worst case without any free tier: under $0.50/month at this usage.
- **No always-on resources:** no EC2, RDS, NAT gateway or EKS.
- **CloudWatch:** 1 alarm using 3 alarm metrics (10 are free); 2 custom metrics `StockProject/ModelHealth` (10 are free).
- **Lambda `stock-evaluate`:** 1 run per weekday, 128 MB; within the free tier.
- **Cognito:** Lite tier, free under 10,000 monthly active users.
- **HTTP API:** about $1 per million requests, with throttling at 10 rps / burst 20.
