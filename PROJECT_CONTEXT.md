### Data model
- **`stock-prices`** (`symbol` / `timestamp`):
  - **Real rows:** `timestamp` is the US close time in UTC (`YYYY-MM-DDT20:00:00Z` during US daylight time, `T21:00:00Z` otherwise). Attributes: `trade_date`, `open`, `high`, `low`, `close`, `volume` (all Numbers), `source=alphavantage`, `data_type=real`, `adjusted=false`, `ingested_at`, `raw_s3_key`. As of 2026-10-26: AAPL 115 real rows (2026-05-12 → 2026-10-23); MSFT, GOOGL, AMZN, NVDA 106 each (2026-05-26 → 2026-10-23).
  - **114 legacy synthetic rows:** unchanged (verified byte-identical to the audit snapshot). They have no `source` attribute, and every reader ignores untagged rows.
- **`stock-predictions`** (`symbol` / `as_of_date`): `predicted_close`, `last_close`, `predicted_change_pct`, `target=next_trading_day_close`, `target_date_estimate`, window dates, `inputs_outside_scaler_range`, `scaler_range`, `model_version`, `execution_id`, `created_at`.

- **`stock-signals`** (`symbol` / `trade_date`): `close`, `prev_close`, `change_pct`, `sma_20`, `sma_50`, `rsi_14`, `volatility_20d_pct`, the prediction, `macd`, `macd_signal`, `macd_hist`, `bb_middle`, `bb_upper`, `bb_lower`, `bb_pct_b`, `alerts[]`, per-type dedup flags `alert_sent_<TYPE>` (conditional write), and `alert_sent_at` / `alert_execution` (first notification). The API marks an alert `test_alert: true` when `alert_execution` is a `test-*` execution.
  - The 2026-10-02 item holds a **test** alert raised with a temporary `PRED_MOVE_PCT=0.1`; it is visible as `alert_execution …:test-signals-alert-2`. The production threshold is 2%.

## 8. Market-data decision (Alpha Vantage)
**Decided 2026-10-04 and implemented 2026-10-05: Alpha Vantage, free API key, `TIME_SERIES_DAILY`, `outputsize=compact`.**

**Free-tier limits:**
- 25 requests per day.
- Each scheduled run uses 5 (1 per ticker; worst case 10 with retries). Testing on 2026-10-05 used about 8; on 2026-10-15, 7 (see the run report).

**Caveats (each is handled in the code or docs):**
1. **Unadjusted prices.** `TIME_SERIES_DAILY_ADJUSTED` is premium-only. Rows carry `adjusted=false`, and a split would show up as a false price jump.
2. **100-data-point limit.** `compact` returns only the latest 100 trading days; `full` is premium-only. That is enough for the 60-row window, but it limits backtesting to 40 points.
3. **The API key travels in the URL** (`apikey=` query parameter). The key lives in SSM SecureString and is fetched at runtime. URLs are never logged, and errors are re-raised without them. Logs and archives were searched to confirm the key isn't there.
4. **Group-project terms question.** The licence covers "personal, non-commercial use"; use "on behalf of a … partnership … or any other association" counts as commercial. **If this is a team project, email support@alphavantage.co** to confirm the use is allowed and request educational verification (which also lifts the request limits).

**Alternatives rejected:**
- Twelve Data free plan: "internal non-display" use only.
- Tiingo free plan: forbids persistent storage.
